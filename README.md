# Полтора года вместе

Сайт-открытка к 18 месяцам отношений (26.04.2025 — 26.10.2026).

- `index.html` — готовая страница, её и раздаёт GitHub Pages
- `src.html` — исходник (фрагмент без `<html>`/`<head>`)
- `build.js` — собирает `index.html` из `src.html`: `node build.js`

Дата начала задаётся в `src.html`, константа `START`.
